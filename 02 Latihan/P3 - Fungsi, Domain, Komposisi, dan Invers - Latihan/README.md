# Latihan Pertemuan 3: Fungsi, Domain, Komposisi, dan Invers

Latihan bertingkat untuk fase Latihan (35 menit) Pertemuan 3 Matematika Dasar (WT25-00001, ITERA). Materinya ada di slide `01 Slide/P3 Fungsi, Domain, Komposisi, dan Invers.pdf` dan modul `03 Modul/Modul 03 - Fungsi, Domain, Komposisi, dan Invers.pdf`.

## Capaian

| Sub-CPMK | Kemampuan |
|---|---|
| 3.1 | Menentukan domain dan range fungsi aljabar serta mengevaluasi fungsi |
| 3.2 | Menyusun operasi dan komposisi fungsi serta menentukan invers fungsi satu-satu |

## Cara mengerjakan

Cetak `Lembar Latihan P3.pdf` atau salin soalnya ke kertas. Tulis nilai $A$ (digit terakhir NIM, kalau 0 pakai 5) dan $B$ (digit kedua dari belakang, kalau 0 pakai 3) di bagian atas. Kerjakan berurutan dari tingkat 1, dan beri satu kalimat alasan di setiap langkah.
